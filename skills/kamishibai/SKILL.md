# kamishibai

The authoritative usage guide ships inside the package — don't guess the API,
print the guide and follow it:

```sh
npx kamishibai skill
```

(or just `kamishibai skill` if it's already installed). It prints the core
guide and a list of topics. Read the core in full, then print the topics your
reel needs, e.g. `npx kamishibai skill audio narration`. The guide is the
source of truth. This skill is only the pointer.
